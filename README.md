# Smart Travel Planner

An AI-Powered Visual Travel Recommendation & Planning System built using Computer Vision, Data Visualization, and Machine Learning.

## Key Features
- **Landmark Classification**: Identification of monuments, heritage sites, and tourism destinations.
- **Scene Recognition**: Places365-compatible scene understanding (mountains, beaches, forests, urban, etc.).
- **Visual Similarity Search**: Image embedding extraction and fast similarity retrieval powered by FAISS.
- **Interactive Dashboard**: Modern React + Vite frontend with dynamic mapping (Leaflet) and data visualizations (Recharts).
- **Backend API**: High-performance FastAPI services with asynchronous endpoints.

## Hardware Acceleration
Optimized for **Apple Silicon (M4, MPS hardware acceleration)**.
